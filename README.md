# Blackline Pitwall — atualizações

Arquivos de atualização do **Blackline Pitwall** (Blackline Motorsport · Team Engineering & Race Operations).

- `updates/latest.json` — ficha da versão mais nova (lida pelo app ao abrir).
- `updates/app-X.Y.Z.asar` — código do app (~1 MB). O app baixa, confere a assinatura SHA-256 e passa a usar ao reiniciar.

Instalação do zero: baixe o pacote completo na página de Releases e extraia numa pasta.
